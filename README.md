# Абрикосовый забег: онлайн-версия

Игра + свой сервер. Работает в любом браузере, без Claude: лобби на 5 человек, друзья бегут рядом с никами, рейтинг по дальности и по абрикосам.

## Запустить у себя на компьютере (1 минута)

1. Установи Node.js (версия 18 или новее): https://nodejs.org
2. В папке проекта выполни:
   ```
   npm install
   npm start
   ```
3. Открой http://localhost:3000. Телефон в той же Wi-Fi сети открывает `http://IP-компьютера:3000`.

## Чтобы друзья играли из интернета

Нужен адрес, который открывается у всех. Два простых способа.

**Способ 1. Бесплатный хостинг (Render).**
1. Залей папку в репозиторий на GitHub.
2. На https://render.com: New, затем Web Service, выбери репозиторий.
3. Build Command: `npm install`. Start Command: `npm start`. План: Free.
4. Render выдаст ссылку вида `https://abricot-run.onrender.com`. Её и отправляй друзьям.

На бесплатном плане сервер «засыпает» без посетителей (первый вход занимает около минуты), а файл рейтинга может сбрасываться при перезапуске. Чтобы рейтинг сохранялся, подключи диск Render (Disks) и задай переменную `DATA_DIR` на его путь.

**Способ 2. С домашнего компьютера через туннель.**
1. Запусти `npm start`.
2. Запусти туннель Cloudflare: `cloudflared tunnel --url http://localhost:3000`.
3. Отправь друзьям выданную ссылку `https://....trycloudflare.com`. Работает, пока компьютер включён.

## Как играть вместе

1. Каждый один раз вводит ник (он запоминается в браузере и на сервере).
2. «Онлайн», затем «Создать лобби». Появится код из 4 символов.
3. Друзья нажимают «Онлайн», вводят код, «Войти». Максимум 5 человек.
4. Создатель лобби нажимает «Старт». Трасса у всех одинаковая.
5. «Рейтинг»: вкладки «Дальше всех» и «Абрикосы».

## Игра как приложение на телефоне

Открой ссылку в Safari (iPhone) или Chrome (Android), затем «Поделиться», «На экран Домой» (iPhone) или меню, «Добавить на главный экран» (Android). Игра откроется на весь экран. Файл APK можно получить из готовой ссылки на сайте https://www.pwabuilder.com.

## Устройство

- `server.js`: раздаёт игру, держит лобби (WebSocket на `/ws`), хранит рейтинг в `data/players.json`.
- `public/index.html`: сама игра (одним файлом).
- Рейтинг привязан к браузеру (идентификатор в localStorage). Другой браузер или очистка данных означает нового игрока.
